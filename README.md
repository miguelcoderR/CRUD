# 🛍️ Product Management

A lightweight web app for registering, editing, and deleting products in real time—no duplicates allowed.



## 🚀 Technologies

- HTML5  
- CSS3  
- JavaScript (ES6+)  



## ✨ Features

- Add products with name, price, and quantity  
- Client-side validation (required fields, non-negative values)  
- Duplicate prevention (case-insensitive name check)  
- Inline editing of name, price, and quantity via `prompt` dialogs  
- Deletion with confirmation dialog  
- Dynamic product list in the DOM, auto-updated after each action
